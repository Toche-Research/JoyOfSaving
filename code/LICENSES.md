# Licences for this replication package

Two different things live here and they carry different licences.

## The code: MIT

Everything under `code/` that was written for this paper is released under the MIT Licence, in
`code/LICENSE`. Use it, change it, redistribute it; keep the copyright notice.

## The generated output: CC BY 4.0

The derived series, tables and figures the scripts write, meaning everything under `code/out/`, are
released under the Creative Commons Attribution 4.0 International Licence
(https://creativecommons.org/licenses/by/4.0/). Reuse them with attribution to the author and to
this paper.

## There are no raw sources

This paper uses no data. Every number, table and figure is produced by the code from the model's
own parameters, so there is nothing here that is not the author's to license. Everything under `code/out/` is simulation output and falls under CC BY 4.0.

This split is the one the AEA Data Editor asks for and the one a journal's data editor will expect:
licence what you made, point at the source for what you did not.
